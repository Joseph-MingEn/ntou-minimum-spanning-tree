# 02 規格

- 頂點 A～F 分別為 0～5；無向邊為 AB4、AC2、BC1、BD5、CD8、CE10、DE2、DF6、EF3。
- Kruskal 儲存 `tuple(w,u,v)` 並排序；併查集 `find` 路徑壓縮，`union` 以較小根編號為父節點。每條邊都顯示是否接受及操作後 p[]，成環明確標示跳過。
- Prim 從 A 開始，`priority_queue` 儲存 `tuple(w,v,from)`，以 `greater` 取最小值，已加入頂點的舊票丟棄。
- 兩者印出接受順序及總重 13。非連通範例使用 AB4、AC2、BC1、DE2，含孤立頂點 F；應有三個分量、三條森林邊、總重 5。
