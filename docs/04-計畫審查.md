# 04 計畫審查

- 同權重以 tuple 的後續欄位決定順序：AC2 排在 DE2 前。Prim 指定由 A 起點，避免順序含糊。
- Kruskal 繼續檢查所有邊，才能完整列出成環跳過；p[] 是每次 find 路徑壓縮及可能 union 之後的實際陣列，未保證所有節點都已壓至根。
- 非連通範例保留孤立頂點 F，森林分量數包含孤立點；避免把森林誤稱生成樹。
